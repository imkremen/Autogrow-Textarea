# Генератор силянки

Веб-застосунок (TypeScript + Vite, без бекенду, рендер у `<canvas>`), що генерує випадкові, але впорядковані
схеми силянки (бісерна сітка). Схему відтворює seed.

Дослідження перед реалізацією: [`../docs/research.md`](../docs/research.md). Там же чесно сказано, що датасету
схем знайти не вдалося, тож діапазони параметрів — проєктні припущення, а не статистика.

```bash
npm install
npm run dev      # локальний сервер
npm test         # vitest: сітка, фризові групи, зв'язність, референс, кольори, експорт
npm run build    # перевірка типів і збірка в dist/
npm run catalog  # оновити каталог Preciosa 10/0 з binyachovo/sylianka
```

## Як влаштовано

| Файл | Що робить |
|---|---|
| `src/lattice.ts` | Модель сітки: `(x, y)`, `u = (x+y)/2`, `v = (x−y)/2`, `s = k+1`, вузли, ромбічні кільця `m = max(|du|, |dv|)`, комірки. |
| `src/frieze.ts` | 7 фризових груп, точкова група за модулем перенесення, канонічний представник орбіти. |
| `src/motifs.ts` | Мотиви як функції `(du, dv) → роль кольору / фон`. |
| `src/params.ts` | Параметри інтерфейсу й повний опис схеми `DesignSpec`. |
| `src/generate.ts` | Випадковий вибір `DesignSpec`: окреме зерно `mulberry32` на кожен шар (для «заморожування»), детерміновані повторні спроби, доки не виконано обмеження. |
| `src/build.ts` | Граматика зверху вниз: горловина → смуга → драбинка → нижня сітка → підвіски → кінчики. Без випадковості. |
| `src/validate.ts` | Зв'язність (BFS), ізольовані бісерини, бісерини на ґратці, фон 40–70 %, 2–5 кольорів, контраст сусідніх кольорів (ΔE OKLab ≥ 0,1). |
| `src/color.ts` | OKLab/OKLCH, традиційні палітри, гармонії, найближчий код Preciosa 10/0. |
| `src/stats.ts` | Бісер по кольорах на раппорт і на всю прикрасу, грами із запасом. |
| `src/export.ts` | JSON, SVG, `.sylianka.json` (формат 2). |
| `src/reference.ts` | Референс «чорний/бордо/золото» як фіксований `DesignSpec`. |

**Симетрія.** Візерунок смуги — `f(b) = f₀(rep(b))`, де `rep` — канонічний образ бісерини в групі.
Тому візерунок інваріантний щодо групи за побудовою, а тести це перевіряють для всіх 7 груп і 1–3 рядів.

**Довжина.** 1 комірка фону + ціле число раппортів + замикальний мотив + 1 комірка фону. Обидва кінці
завершуються цілим мотивом, а за вертикальних дзеркал уся прикраса симетрична.

**Посилання.** Seed, параметри й заморожені шари зберігаються в адресі (`#seed=…&type=…`), тож кнопка
«Копіювати» дає посилання, яке відтворює схему. `#ref` відкриває референс.

## Сумісність із sylianka

`side = k + 2`, `lx = x/s − 1`, `ly = y/s`. Тест `tests/export.test.ts` перебудовує ключі бісерин так само,
як `buildGeometry` у sylianka, і перевіряє збіг бісерина в бісерину для k = 1…4. Драбинку й частини поза
прямокутником формат sylianka не описує, тому в трафарет вони не потрапляють. Застосунок про це попереджає.
